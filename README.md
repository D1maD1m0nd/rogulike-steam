# Steam Draft

Steam Draft — браузерный карточный роглайк для знакомства с играми Steam. В забеге реальные игры становятся картами с уроном и защитой. Для выбора игры на вечер есть быстрый подбор с фильтрами, коллекция и голосование по ссылке. Правила и сценарии описаны в [PRODUCT.md](PRODUCT.md).

## Что установить

Для запуска нужны **Bun 1.4.2** и современный браузер. Bun запускает NestJS и собирает React. Бэкенд работает с локальной SQLite через Prisma. Все npm-пакеты устанавливаются одной командой из корня репозитория.

### Windows

В PowerShell установи версию Bun, указанную в проекте. [Документация Bun по установке версий](https://bun.com/docs/installation#installing-older-versions)

```powershell
iex "& {$(irm https://bun.com/install.ps1)} -Version 1.4.2"
```

### Linux и macOS

```sh
curl -fsSL https://bun.com/install | bash -s "bun-v1.4.2"
```

После установки открой новый терминал и выполни `bun --version`. Для этой версии проекта ожидается `1.4.2`.

## Локальный запуск

Из корня репозитория выполни:

```sh
bun install --frozen-lockfile
bun run db:migrate
bun run dev
```

Открой [Steam Draft](http://127.0.0.1:3000/). Bun обслуживает интерфейс на порту `3000` и перенаправляет запросы `/api` в NestJS на порт `3001`. Проверь ответ `{"ok":true}` на [маршруте проверки сервера](http://127.0.0.1:3001/api/health).

Приложение запускается со стартовым каталогом из **90 игр Steam для региона RU**. Команда `bun run db:migrate` создаёт `data/steam-draft.sqlite` и применяет миграции. `bun run dev`, `bun run build` и `bun run typecheck` генерируют Prisma Client.

### База, созданная до подключения Prisma

Останови приложение и сохрани резервную копию базы. Один раз отметь исходную схему как уже применённую, затем запусти следующую миграцию. Она переносит существующие записи со старыми идентификаторами. Для новой базы из предыдущего раздела этот шаг пропускается.

```sh
bun run prisma migrate resolve --applied 20261120000100_legacy_schema
bun run db:migrate
```

Проверить состояние можно командой `bun run prisma migrate status`. Схема описывает профили, подборки и голосования, списки игр, каталог Steam и курсор его импорта, а также забеги. Схема и SQL-миграции хранятся в репозитории. [Схема Prisma](backend/prisma/schema.prisma) · [Миграции](backend/prisma/migrations)

### Проверка типов и запуск сборки

```sh
bun run typecheck
bun run build
bun run start
```

Для запуска сборки сначала останови режим разработки, если он занимает порт `3001`. Открой [собранное приложение](http://127.0.0.1:3001/). NestJS обслуживает API и готовый интерфейс из `frontend/dist`. Серверная сборка находится в `backend/dist`.

## Настройки окружения

Для изменения настроек скопируй [.env.example](.env.example) в `.env` в корне проекта.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Адрес, на котором слушает NestJS |
| `PORT` | `3001` | Порт NestJS. Интерфейс разработки открывается на `3000` |
| `DATABASE_PATH` | `data/steam-draft.sqlite` | Путь к SQLite, относительный путь считается от корня проекта |
| `STEAM_COUNTRY` | `ru` | Регион витрины и цены |
| `STEAM_LANGUAGE` | `russian` | Язык описаний, если перевод доступен в Steam |
| `STEAM_WEB_API_KEY` | пусто | Ключ для импорта новых App ID через Steam Web API |
| `COOKIE_SECURE` | автоматически по типу соединения | Значение `true` требует HTTPS для браузерной cookie сессии |

Прогресс хранится в SQLite и привязан к cookie браузера. Для голосования по ссылке друг должен иметь доступ к тому же экземпляру приложения. Адрес `127.0.0.1` доступен с компьютера, на котором запущен сервер.

## Обновление каталога Steam

```sh
bun run catalog:seed
```

Команда заново проверяет стартовый список App ID и обновляет [снимок каталога](backend/src/catalog/steam-snapshot.json) с ценой, основным жанром и счётчиками отзывов Steam. После смены региона или языка обнови снимок и перезапусти приложение. Если запускаешь готовую сборку, перед перезапуском выполни `bun run build`. Актуальная цена и доступность указаны на странице игры в Steam. [Steamworks API отзывов](https://partner.steamgames.com/doc/webapi/IUserReviewsService)

Для добавления игр за пределами стартового списка задай обычный Steam Web API key в `STEAM_WEB_API_KEY` в локальном `.env`. Скрипт проверяет до 100 записей за один запуск, дополняет SQLite и сохраняет позицию для следующей порции. [Steamworks IStoreService](https://partner.steamgames.com/doc/webapi/IStoreService)

```sh
bun run catalog:sync 100
```
